# Filter Dataset Records Using Pandas

## Project Overview

This project demonstrates how to filter dataset records using Python Pandas.

A student performance dataset is created and different conditions are applied to retrieve relevant records.

## Objectives

- Learn DataFrame filtering using Pandas
- Apply single conditions
- Apply multiple conditions
- Use AND and OR operators
- Understand Boolean filtering

## Technologies Used

- Python
- Pandas
- Google Colab

## Filtering Examples

### 1. Marks Greater Than 80

Filters students whose marks are greater than 80.

### 2. Attendance Greater Than or Equal to 90

Filters students with attendance of at least 90%.

### 3. Multiple Conditions

Filters students whose marks are greater than 75 AND attendance is greater than 85.

### 4. OR Condition

Filters students who belong to the AI department OR have marks greater than 85.

## Key Learning

This project helped me understand how Pandas Boolean conditions can be used to retrieve specific records from a DataFrame.

## Conclusion

Pandas filtering is an important data analysis technique that helps retrieve relevant records based on specific conditions.
